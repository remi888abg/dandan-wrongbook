# 蛋蛋错题本 (dandan-wrongbook)

一个零依赖、可离线使用的错题本 PWA。单文件 HTML + Service Worker，数据全部存在设备本地，不上传任何服务器。

支持 iPad「添加到主屏幕」、鸿蒙 / 安卓「添加到桌面」，装上后跟原生 App 一样用，断网照常记错题。

---

## 功能

| 模块 | 说明 |
| --- | --- |
| 多科错题 | 语文 / 数学 / 英语…… 科目可自定义 |
| 错题字段 | 题目、我的答案、正确答案、错因分析、知识点、难度、日期、标签 |
| 题目图片 | 拍照或相册上传，自动压缩到 ≤1000px 省空间 |
| 艾宾浩斯复习 | 1 / 2 / 4 / 7 / 15 / 30 / 60 天节奏，「记住了 / 没记住」自动排下次 |
| 待复习 | 单独页签，列出今天该复习的错题 |
| 搜索筛选 | 关键词搜索 + 按科目 / 标签过滤 |
| 统计 | 各科分布、掌握率 |
| 备份 | 导出 / 导入 JSON，支持「合并」与「覆盖恢复」两种模式 |
| 打印 | 一键生成打印版，可存为 PDF |
| 密码保护 | 开屏登录锁 + 危险操作二次验密 |
| 手势护栏 | 拦截手机左右滑返回，防止误退出应用 |
| 题目 OCR | 编辑页「🔍 识别题目」：联网时调用本地 Tesseract.js（chi_sim）识别题目图片文字并填入；离线或被墙时提示「无网络，无法识别」 |
| 检查更新 | 设置页「检查更新」：联网静默比对 `version.json`，发现新版可一键重启更新；本地错题记录（localStorage）完整保留。更新逻辑不向界面展示任何在线网址 |

## 密码

应用有两套密码，均为本地散列存储（非明文），可在「⚙️ 设置」页自行修改。

| 用途 | 默认值 | 说明 |
| --- | --- | --- |
| 登录密码 | `180515` | 开屏解锁。同一次会话只需输一次 |
| 操作密码 | `@123456` | 进入设置页、覆盖恢复、清空数据时验证 |

> 属于「防偷看 / 防误删」级别的保护，不是加密存储。忘记密码不会丢数据，但需要清理浏览器 localStorage 中的密码键重置。

## 安装使用

### iPad / iPhone

1. Safari 打开部署地址
2. 底部「分享」→「添加到主屏幕」
3. 从主屏图标启动，此后断网可用

### 鸿蒙 / 安卓

1. 用华为浏览器 / Chrome 打开部署地址（**不要**用微信、QQ 内置浏览器）
2. 菜单 →「添加到桌面」/「发送到桌面」
3. 从桌面图标启动

### 纯本地（不依赖网址）

把 `index.html` 传到设备，用浏览器打开即可。注意：此模式下 Service Worker 不生效（`file://` 协议限制），但所有功能正常，数据照常保存。

## 数据备份与迁移

数据存在浏览器 `localStorage`，**换设备、换浏览器、清缓存都会丢失**，务必定期备份。

1. 进入「⚙️ 设置」页（输入操作密码 `@123456`）
2. 点「⬇️ 导出错题」，生成 `蛋蛋错题本备份_日期.json`
3. 新设备上进设置页 →「📥 导入错题（合并）」或「♻️ 导入错题（覆盖恢复）」

两种导入模式的区别：

- **合并** — 把备份里的错题追加到当前本子，按 id 自动去重，适合多设备汇总
- **覆盖恢复** — 用备份整体替换当前数据，复习进度一并还原，适合换设备或重装后还原

导出的 JSON 包含完整的错题内容、图片和复习状态（`reviewStage` / `mastered` / `reviewHistory`），还原后艾宾浩斯排期无损。

## 部署

纯静态站点，把仓库根目录托管到任意静态服务即可。

**GitHub Pages**：Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。`.nojekyll` 已就位，下划线开头的文件不会被 Jekyll 吞掉。

所有资源引用均为相对路径（`./xxx`），部署在子路径（如 `/dandan-wrongbook/`）下也能正常工作。

## 开发说明

### Service Worker 缓存策略

采用**网络优先**：联网时总是拉最新版本并更新缓存，断网时回落到缓存。这样每次更新代码，用户刷新一次就能拿到新版，不会被旧缓存卡住。

> ⚠️ 改动默认密码或其他 localStorage 配置时，必须同时做两件事：① 升级 `localStorage` 键名版本号；② 升级 `sw.js` 里的 `CACHE` 版本号。否则老设备上旧值残留 + 旧缓存生效，改动不会起作用。

### 跑测试

```bash
npm install    # 安装 jsdom
npm test
```

测试覆盖：种子数据注入、备份面板交互、导出 JSON 合法性、合并导入去重、覆盖恢复后逐条比对、损坏文件容错、空备份拒绝、双密码验证（登录 / 操作）、改密后旧密码失效等，共 30 项。

## 技术栈

无框架、无构建、无外部依赖。原生 HTML + CSS + ES5 JavaScript 单文件，配合 Service Worker 实现离线。测试用 Node.js + jsdom。
